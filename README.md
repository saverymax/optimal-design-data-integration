This is the repository for our research on the Bayesian optimal design of sampling locations when integrating presence-only and presence-absence data in Bayesian site occupancy models.

Instructions regarding running the code, data processing, and implementation of the associated paper can be found in the documentation provided with this repository, available at <https://saverymax.github.io/optimal-design-data-integration/>. Unprocessed data files to recreate the case-study can be found at <10.6084/m9.figshare.25450108>. Pre-processed data is available within this GitHub repository and described within the documentation.
