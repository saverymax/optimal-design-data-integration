This is the repository for our research on the Bayesian optimal design of sampling locations when integrating presence-only and presence-absence data in Bayesian site occupancy models. The corresponding paper can be found at <https://doi.org/10.1214/25-BA1581>. If you make use of the paper or code please cite
```
Max Savery. Stijn Luca. "Bayesian Optimal Design for Occupancy Modelling Using Integrated Presence-Only and Presence-Absence Data." Bayesian Anal. Advance Publication 1 - 24, 2025. https://doi.org/10.1214/25-BA1581
```

Instructions regarding running the code, data processing, and implementation of the associated paper can be found in the documentation provided with this repository, available at <https://saverymax.github.io/optimal-design-data-integration/>. Unprocessed data files for recreating the case-study can be found at <https://doi.org/10.6084/m9.figshare.25450108>. Pre-processed data is available within this GitHub repository and described within the documentation.
