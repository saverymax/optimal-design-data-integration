This is the repository for work on Bayesian optimal design of sampling locations when integrated presence-only and presence-absence data in Bayesian site occupancy models.

Currently, this code implements an exchange algorithm to search for optimal spatial locations in a region of interest. 
To do so, it takes a site-occupancy model for presence-absence data, while using as a poisson process prior based on presence-only data.
Integrating data in this fashion allows us to incorporate more information than would otherwise be gained by using presence-absence data alone.
