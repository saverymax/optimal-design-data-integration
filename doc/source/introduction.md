
Welcome to the documentation for the repository "optimal-design-data-integration". 

The aim of this project is to explore the integration of presence-absernce and presence-only data when designing surveys in biodiversity monitoring contexts. In this documentation you can find details regarding the usage of the code for designing surveys, implementation of the optimal design algorithms, and data relevant for the project.

To get started, please [clone the repository](https://github.com/saverymax/optimal-design-data-integration) and follow along with the documentation here.
