# Usage

Usage of this code is described here. The simulated experiments and the applied experiments (to Brown-headed Nuthatch data) are run in separate scripts. The use of each will be explained.

## Simulated settting


### CLI Arguments

The parameters used in the code are as follows, as per the argument parser used in the main script. Run "Rscript.exe optimal_design_site_occ.R --help" to see the help shown below:

```
Options:
        -h, --help
                Show this help message and exit

        --working_dir=WORKING_DIR
                Path to the directory containing code to source for the main script and associated functions

        --save_dir=SAVE_DIR
                Path to save experimental results. Typically set to experimental_runs/name-of-experiment within the working directory.

        --po_data_file=PO_DATA_FILE
                File name of PO data to use in optimization

        --exp_name=EXP_NAME
                Name of current experiment, which is used to name unique dir to save output

        --use_sim_po
                Use PO generated by simulation. Check on user so that PO data is pre-simulated beforehand.

        --data_reps=DATA_REPS
                Number of dataset reps for criterion estimation. The V criterion is estimated as an expectation through numerical integration. data_reps is the number of integration points.

        --m=M
                Number of sites to survey. We will randomly select m sites to use in the exchange algorithm. While it would be interesting to optimize this during the exchange algorithm, at the moment this is computationally intensive and we leave this as a fixed integer.

        --max_visits=MAX_VISITS
                Maximum number of time to visit each site

        --min_visits=MIN_VISITS
                Minimum number of time to visit each site

        --vary_visits
                Allow varying survey effort between sites

        --model_selection=MODEL_SELECTION
                Occupancy model to use. Further details are provided in the modelling section of the documentation.

        --random_starts=RANDOM_STARTS
                Number of random starts to run the exchange. The exchange algorithm is run multiple times to average over the random m sites initially selected.

        --exch_iter=EXCH_ITER
                Number of iterations of exchange before ending optimization. Recommended is 20 but default is set low for test runs.

        --mcmc_iter=MCMC_ITER
                Number of MCMC iterations in Stan

        --intensity_func=INTENSITY_FUNC
                Intensity function for sampling surface. This can be set as 'donut' or 'simple'

        --bias_func=BIAS_FUNC
                Bias function for sampling surface. Currently can be generated as either an 'exponential' mountain from a single point in the region, or with 'correlation' as a donut correlated with the intensity.

        --p_logging
                Boolean for logging information about posterior estimates fit in Stan, when using nonparallel code. The implementation of this is currently not tested and should be left as False

        --debug_stan
                Boolean for turning on messages from stan model in nonparallel V. Useful to see any issues during fitting.

        --v_parallel
                Boolean for parallel computation of V criterion, if you have have multiple cores available that are compatible with the R parallel library

        --cores=CORES
                Number of cores to use for parallel processing

        --alpha=ALPHA
                Intercept for intensity

        --beta=BETA
                Slope for intensity. The parameters for that specify the intensity and models will be explained in greater detail in the modelling section.

        --gamma=GAMMA
                Intercept for bias

        --delta=DELTA
                Slope for bias

        --sd=SD
                Standard deviation for donut intensity surface. Not permuted during experiments but it can have a large effect on exchange algorithm.

        --p=P
                Probability of detection

        --area=AREA
                Area of region D.  This is important in order to correctly scale the covariates.

        --k=K
                Number of sites along one side of grid

        --aux_cor=AUX_COR
                Correlation between auxiliary covariates if using 'correlation' bias function.
```


### Running

For example, you can run an experiment like this
```
Rscript optimal_design_site_occ.R --working_dir=. --exp_name=oe_run --data_reps=100 --m=5 --n=5 --model_selection=3 --random_starts=3 --exch_iter=20 --mcmc_iter=1000 --intensity_func="donut" --bias_func="exponential" --v_parallel --cores=48 --alpha=-2 --beta=0.5 --gamma=1 --delta=0.25 --p=0.2 --aux_cor=0.8
```

Setting the initial values for the alpha, beta, gamma, and delta parameters will control the data generation process 
and specify a higher or lower intensity and bias.

The experimental results will be written to a folder named experimental_runs, which you have to create yourself. However, this will include only plots from the exchange and figures of the intial data generation. The rest of the output printed during the experiment is written to std-out, which is also up to you how to control. Typically I write these to properly named .o and .e files when running on the HPC cluster.
